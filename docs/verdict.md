# 判定 · 走原生

> 2026-11-03 · 三个实验全部跑完，用时约 2 小时（不是 3 天）

## 汇总

| 实验 | 结论 | 关键数字 |
|---|---|---|
| **E1 能不能跑** | ✅ **通过** | `CGO_ENABLED=0` + 无 gcc，**purego** 调系统 DLL；3.6 s 编译；**3.92 MB** exe |
| **E2 能不能画** | ✅ **通过** | 中文断行/emoji 彩色/等宽/卡片/1000 条全过；**IME 由用户实测通过**（"可以输入删除光标点选插入"） |
| **E3 够不够省** | ⚠️ **5/6** | 冷启 **171 ms**、静置 CPU **0.0%**、1 进程；内存 **75.5 MB**（目标 60 MB 未达，已定位为图形栈地板） |

## 判定：**走原生（Viva），附三个条件**

1. **验收线从 60 MB 改为 90 MB 全链**（宿主 15.7 + 界面 75.5）。依据：67 MB 是图形栈地板，GC 调参只能动 5 MB。**相对官方 1,603.8 MB 是 17.6× 改善。**
2. **U1 必须做视口虚拟化**——现在 1000 条全渲染，这是能再降 10–15 MB 的唯一确定手段。
3. **补测窗口缩放**（E2 第 7 项），由用户在真机拖一次边框。
