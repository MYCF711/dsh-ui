## 空闲内存为什么超标：拆开看

**Viva 空窗口本身就要 67.2 MB。** 我们的 1000 条内容只加了 8.3 MB。

用 `GOGC` 调 Go 堆，几乎无效：

| GOGC | WorkingSet | Private |
|---:|---:|---:|
| 100（默认） | 75.4 MB | 88.3 MB |
| 50 | 74.4 MB | 84.6 MB |
| 20 | 74.1 MB | 84.9 MB |
| 10 | 70.6 MB | 86.6 MB |

**结论：这 67 MB 不是 Go 堆，是图形栈固定成本**（D3D11 设备 + 交换链 + DirectWrite/字体缓存 + 系统 DLL 映射）。**GC 调参救不了它。**
