## 两个真问题（要在 U1 处理）

1. **代码块没有横向滚动**。Viva 的 `ScrollArea` 只给纵向（column）；等宽代码在窄窗口下必然溢出。U1 至少要满足其一：
   - 找 `flex` 里有没有横向滚动容器（本次只读了 `hello/AGENTS.md`，**未确认是否存在横向 Scroll**）；
   - 或代码块改用「软换行 + 行号对齐」；
   - 或给代码块设 `MinWidth`，让外层整体横向滚动。
2. **`Grow(1)` 在空间不足时会塌成 0 高度**，列表"消失"。U1 需要给滚动区一个 `MinHeight`，或让整页在最小时可整体滚动，而不是让某一块被挤没。

## 如果要在 U1 里用，需要注意什么

| # | 注意点 |
|---|---|
| 1 | **会话区必须自己是一个 `ScrollArea`，且带 `MinHeight`**；否则窗口一矮，消息列表就没了 |
| 2 | **代码块要单独解决横向溢出**（U1 的 diff/代码视图会遇到同样问题，且更严重） |
| 3 | **窗口最小尺寸要设死**（Viva `Config` 有 `MinWidth/MinHeight`，本次未验证）——低于这个尺寸就会出现第 6、7 条的现象 |
| 4 | 中文断行**不用管**，引擎按 UAX #14 + kinsoku 处理得是对的；但要在 UI 上避免让一两个汉字孤零零留在末行（这是排版层面的 `text-wrap: balance` 类工作，Viva 是否支持未确认） |
| 5 | 缩放后**不需要手动重绘**，事件驱动已经覆盖；三档都没有闪白 |
| 6 | 内存**不会**随窗口变大显著上升（1500×900 与 1100×860 都是 83.1 MB），说明交换链不是按面积线性吃内存 |
